# 검증 기록 — 2026-10-30

2025년 팀 저장소 Jongp의 ai/src/train.py와 ai/src/score.py에 남아 있는 모델 구조, 학습 파라미터, 추천 점수 방식을 확인했다. 이 폴더의 코드는 이를 참고해 다시 작성한 것이다.

## 확인한 내용

- Python 3.13.5, pandas 2.2.3, scikit-learn 1.8.0, XGBoost 3.1.3, pytest 9.0.2
- pytest 단위 테스트 **8개 통과**
- compileall 구문 검사 통과
- 합성 데이터 생성 → 모델 학습 → joblib 저장 → 예측 입력 검증 완료
- JSON 입력으로 네 가지 우선순위별 추천 점수 출력 확인

가상 데이터 45일(주차장 3곳) 학습 예제에서 MAE 약 0.021, R² 약 0.99999가 나왔다. 단순한 주기함수로 만든 데이터라 실제 주차장 예측 성능과는 관계없다.

## 확인이 더 필요한 부분

- 실제 데이터에 실측 점유율/혼잡도 정답이 포함돼 있는지
- 원본 데이터의 누적 입·출차량으로 산출한 혼잡도와 실측 혼잡도의 차이
- 실제 데이터에서 시간순 홀드아웃 성능
- 운영 시점에 과거 혼잡도·입출차량이 지연 없이 확보되는지
- 서버와 프론트엔드에 연결했을 때의 인터페이스

기존 원본을 수정하거나 이전 평가 수치를 재현한 결과는 아니다. 현재 GitHub에 올린 것은 검증 가능한 학습/추천 코드와 합성 데이터 예제다.
