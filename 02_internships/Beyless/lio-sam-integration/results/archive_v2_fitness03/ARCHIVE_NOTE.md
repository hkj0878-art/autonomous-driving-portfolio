# v2 기본 fitness=0.3 전체 배치 보존

RPY 정정 후 rate=1.0으로 사전에 정한 ON 3회/OFF 3회/even 1회를 모두 수행한 결과다. 7개 모두 거리/속도 sanity 통과. ON r2 loop=0, 종점 비교 [True, False, False]로 전체 기준 미충족. 실패 run만 골라 바꾸지 않고 전체 배치를 보존한다.

사후 궤적 검사에서 ON r2는 15m/30s 후보 keyframe 17개, 마지막 최근접 거리 6.389m다. ICP fitness/수렴/특징점 개수는 업스트림이 로그하지 않으므로 거부 원인을 확정할 수 없다. 다른 파라미터를 고정하고 fitness 임계값만 0.3→0.5로 변경한 별도 trial이 loop=3 및 sanity 통과해, 전체 반복 배치를 새 설정으로 다시 수행한다. 기존 파일의 경로 문자열은 원 실행 경로를 보존한다.
