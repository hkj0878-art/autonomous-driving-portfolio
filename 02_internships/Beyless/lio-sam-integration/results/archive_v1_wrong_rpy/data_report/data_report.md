# TASK-02 데이터 리포트

- 제거 비율: 50.5131% (nonfinite → origin → near 순으로 상호 배타적 집계)
- offset = header stamp − 전체 입력의 유한한 timestamp 최솟값
- offset 평균 169765152.463684797 s, 표준편차 0.000000000 s, 평균 대비 최대편차 0.000000000 s, 전체 범위 0.000000000 s
